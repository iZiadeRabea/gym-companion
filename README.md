# Gym Companion | رفيق الجيم

Mobile-first workout logging PWA. Tracks workout sessions, exercises, sets, reps, weights, timing, rest, and progress. Includes customizable plans and pre-exercise safety questions. Prototype v1.1.1; not medical advice. **Demo simulation mode** tests the timer without requiring or implying medical clearance.

## Publish on GitHub Pages

1. Create a GitHub repository and put the files from this folder in the **repository root** (so `index.html` is directly visible on the Code tab).
2. Go to **Settings → Pages → Build and deployment**.
3. Choose **Deploy from a branch**, then select **main** and **/(root)**, and click **Save**.
4. Open `https://USERNAME.github.io/REPOSITORY/` from Safari on your iPhone. Choose **Share → Add to Home Screen**.

## Storage and privacy

Workout data is stored on the current browser/device only using localStorage; this prototype does not sync or have accounts. GitHub hosts only the static code, NOT your training records. Use **Settings → Export JSON** to keep a backup. Avoid committing personal medical records to this repository. The Pages website is publicly accessible, even if a paid plan allows a private repository.

The app is a demo, and its suggested exercises, loads, and timings must be reviewed by a qualified treating professional before use. Exercise photos/videos are planned but not included yet.
